<div align="center">
    <h2>🗂 Estrutura do projeto</h2>
</div>

```text
src/main/java
├─ application/
│  └─ utilitarios/    -> ferramentas e apps (snippet, markdown, mockapi, conversores...)
├─ games/
│  ├─ strategy/       -> jogos estratégicos
│  ├─ puzzle/         -> quebra-cabeças
│  ├─ narrativo/      -> jogos com narrativa
│  └─ text/           -> jogos textuais
├─ math/
│  ├─ numerico/       -> raízes, integração, interpolação, sistemas lineares
│  ├─ estatistica/
│  └─ probabilidade/
└─ cursos/            -> exercícios e projetos de aula
```

<div align="center">
    <h2>▶️ Como executar</h2>
</div>

**Pela IDE (recomendado):**
1. Abra o projeto no IntelliJ.
2. Navegue até uma classe `Principal...`.
3. Execute o método `main`.

**Via terminal (javac/java):**
```bash
javac -encoding UTF-8 -d out src/main/java/caminho/do/Arquivo.java
java -cp out pacote.ClassePrincipal
```
